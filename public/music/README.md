Add these short looping instrumental tracks here; use royalty-free/licensed audio and keep each reasonably small:

- `birthday.mp3` — opening, gallery, present wishes, wish jar, and timeline.
- `dream.mp3` — DU dream and HSC result chapters.
- `soft-wishes.mp3` — prayer and promise chapters.
- `letter.mp3` — the letter chapter.
- `happy-birthday.mp3` — finale. If absent, the app plays a built-in synthesized birthday melody.

The app starts a soft original Web Audio ambient bed after the “Tap to begin” gesture, so a missing uploaded track does not leave the experience silent. Tracks crossfade as chapters change.
